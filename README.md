# Model

The energy $U$ is given by the Hessian matrix $H_{ij}$ with the displacement fields $x_i$ and the Heisenberg parameter $J_{ij}$ and the magnetic moments $m_i$ with the cross terms $K_{ij}$ and $L_{ij}$, including the longitudinal terms $A_k$

$$
U = \frac{1}{2} \sum_{ij} H_{ij} x_i x_j-\sum_{ij} \left(\frac{1}{2}J_{ij} m_i m_j + K_{ij}x_ix_jm_i + \frac{1}{2}L_{ij}x_ix_jm_im_j\right) + \sum_k \sum_i A_k m_i^{2k}
$$
