# Model

The energy $\mathcal H$ is given by the Hessian matrix $H_{ij}$ with the displacement fields $x_i$ and the Heisenberg parameter $J_{ij}$ and the magnetic moments $m_i$ with the cross terms $K_{ij}$ and $L_{ij}$, including the longitudinal terms $A_k$

$$
\mathcal H = \frac{1}{2} \sum_{ab} H_{ab} u_a u_b- \frac{1}{2}\sum_{ij}J_{ij} \mathbf m_i \cdot \mathbf m_j + K_{ij}x_ix_jm_i + \frac{1}{2}L_{ij}x_ix_jm_im_j + \sum_k \sum_i A_k m_i^{2k}
$$
